## Files and reproduction

The flat ZIP contains a source package, a complete Git bundle for branch
`dev/glmmtmb-poisson-rs`, validation reports, returned logs, and check evidence.
The source package contains the runnable package and tests; the Git bundle
also retains all benchmark builders, independent audits, and project history.

Key repository files:

- `R/adapters.R`, `R/internals.R`, and `R/marginaleffects-methods.R`: existing adapter,
  score, covariance, and prediction integration (consult actual symbols before
  making changes; this checkpoint added validation, not implementation edits).
- `tests/testthat/test-glmmtmb-poisson-rs.R`: numerical score, prediction,
  slope, support-boundary, scaling, and sample-pattern tests.
- `tests/testthat/test-glmmtmb-poisson-rs-stata.R`: 53 component/joint
  expectations against returned Stata evidence.
- `tests/testthat/fixtures/glmmtmb-poisson-rs-stata-components.rds`: six
  components, data, and native margins from v2.
- `tests/testthat/fixtures/glmmtmb-poisson-rs-stata-balanced-v4.rds` and
  `glmmtmb-poisson-rs-stata-remaining-v5.rds`: untouched raw joint output and
  its full parameter/covariance transformations.
- `tools/stata-benchmarks/README.md`: exact reference-generation, parser,
  comparison, and audit commands; run these tools from that directory.

The benchmark CSV is unchanged (SHA256
`5de275159d9548c8eacf6ad65811479defcf8787d3ba5163a7b80cd835762a1e`).
R reference output is generated by `run_glmmtmb_poisson_rs_reference.R`.
The generalized audit independently computes Laplace likelihood derivatives
for balanced, partial/higher-clustered, and disjoint cases. Disjoint R and
independent cross-model covariance are exactly zero. Raw GSEM covariance
requires the labeled 99/98 cluster normalization before comparison.
